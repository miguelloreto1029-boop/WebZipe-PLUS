# Guía de publicación de Camello

1. Descarga una copia de seguridad del repositorio actual.
2. Descomprime `Camello-GitHub-Pages-listo.zip`.
3. Sube todos los archivos y carpetas de su interior a la raíz del repositorio `WebZipe-PLUS`, rama `main`.
4. Acepta reemplazar `index.html`, `manifest.webmanifest` y `sw.js` por las versiones de este paquete.
5. En GitHub entra a Settings → Pages.
6. Selecciona Deploy from a branch → `main` → `/(root)` → Save.
7. Espera a que GitHub Pages publique el sitio.
8. Abre `https://miguelloreto1029-boop.github.io/WebZipe-PLUS/`.

Si el navegador muestra una versión antigua, realiza una recarga forzada o borra los datos del sitio para eliminar una caché anterior.

El archivo BAT se conserva como utilidad local opcional, pero ya no es necesario para abrir la versión web.
